# Dataset attribution and license

This project uses the **Wine Quality** dataset from the UCI Machine
Learning Repository:

- Creators: Paulo Cortez, A. Cerdeira, F. Almeida, T. Matos, and J. Reis
- Dataset DOI: https://doi.org/10.24432/C56S3T
- UCI page: https://archive.ics.uci.edu/dataset/186/wine+quality
- License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)

This project uses the red-wine file, which contains 1,599 Portuguese Vinho Verde
rows. Eleven physicochemical measurements are the input features, and a sensory
quality score from 0 to 10 is the target. The observed red-wine scores in this
file range from 3 to 8. The classes are ordered and imbalanced. The modeling
pipeline documents and removes 240 exact duplicate rows before data splitting.
